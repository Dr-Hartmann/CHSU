# Абстрактный класс

> ***Абстрактный класс*** - это неполный (родительский) класс, возможно шаблонный, который служит базой для других классов (дочерних классов или потомков), может содержать объявления методов (абстрактные методы или контракт, который обязательно должен быть реализован в любом неабстрактном классе-потомке) и существует только для наследования (нельзя создать объект абстрактного класса напрямую ).
