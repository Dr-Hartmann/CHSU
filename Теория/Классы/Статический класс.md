# Статический класс

> ***Статический класс*** - это *класс*, который содержит только набор глобальных констант и утилит (статические поля и методы) с доступом через имя класса, и не может быть базовым классом (участвовать в наследовании) и не может быть классом, на основе которого не создаются объекты.
