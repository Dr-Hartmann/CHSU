# Класс-интерфейс

> ***Интерфейс*** — в широком смысле — формально определенная логическая и/или физическая граница между отдельными объектами, которые обмениваются информацией. Интерфейс задает параметры, процедуры и характеристики взаимодействия объектов.

> ***Интерфейс*** - это [[Класс|класс]]-контракт, содержащий только объявление операций (параметров, процедур и характеристик взаимодействия объектов), которые обязательно должны быть реализованы любым классом, наследующим (реализующим) этот интерфейс.
 
Интерфейсы широко применяют при разработке ***сетевого программного обеспечения***, которое должно идентично функционировать в гетерогенных средах, а также для организации взаимодействия с [[../Базы данных/Понятие системы управления базами данных (СУБД)|системами управления базами данных]] и т. п., так как механизм полиморфного наследования (***полиморфизма***) позволяет создавать различные реализации одного и того же интерфейса.

Один класс может реализовывать несколько интерфейсов (множественная реализация) и, обычно, не может быть наследником нескольких базовых классов.
