Функция вычисления средней ставки ЦБ на диапазоне в зависимости от изменений во времени:

Она рассчитывает:

$$Средневзвешенная~ставка=\frac{∑_{ставки}​(Дней~действия~×~Ставка)}{Общее~число~дней~в~периоде}$$

```excel
=LAMBDA(a;b;dates;rates;datess; LET(start; MAP(dates; LAMBDA(x; МАКС(a; x))); stop; MAP(datess; LAMBDA(x; МИН(b+1; ЕСЛИОШИБКА(x; b+1)))); СУММПРОИЗВ(ЕСЛИ(start < stop; (stop - start) * rates; 0)) / (b - a + 1)))
```

```excel
=LAMBDA(a;b;dates;rates;datess;
	LET(
		start; MAP(dates; LAMBDA(x; МАКС(a; x)));
		stop; MAP(datess; LAMBDA(x; МИН(b+1; ЕСЛИОШИБКА(x; b+1)))); 
		СУММПРОИЗВ(
			ЕСЛИ(start < stop; (stop - start) * rates; 0)
		) / (b - a + 1)
	)
)
```
