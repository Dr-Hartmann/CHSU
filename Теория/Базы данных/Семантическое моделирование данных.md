# Семантическое моделирование данных

[[Реляционная модель БД|Реляционных БД]] достаточно для моделирования большинства предметных областей. Но при реальном проектировании обнаруживается их ограниченность, у модели нет достаточных средств для отражения смысла данных. Трудно моделировать предметную область на основе плоской таблицы.

> ***Проектирование*** - это выделение сущностей и связей между ними. Модель не предполагает аппарата для разделения сущностей и связей. В развитии реляционной модели появилась семантическая модель данных **Entity Relationship (ER)**. Эта модель рисуется в виде [[../ER-диаграмма|ER-диаграмм]]. Моделирование базируется на графических диаграммах.

## История реляционных БД
Первая экспериментальная реляционная [[Понятие системы управления базами данных (СУБД)|СУБД]] - **System R**. Придумана фирмой IBM в 1975-1979 гг.
