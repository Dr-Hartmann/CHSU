# Маска подсети

> ***Маска подсети*** — это число, применяемое в паре с [[../Протоколы передачи данных/Протокол IP. IP-адрес|IP-адресом]], для [[Сегментация сети|сегментации сети]], причём двоичная запись маски содержит непрерывную последовательность единиц в тех разрядах, которые должны в IP-адресе интерпретироваться как номер сети.

Маска состоит из:

- ***адреса сети (Network Address)*** - номер сети, который показывает к какой сети принадлежит адресат, который получается путем применения побитовой логической операции "И" к IP-адресу и маске;
- ***адреса машины (Host Address)*** - номер узла в сети (хоста), с помощью которого хост-часть идентифицирует сетевое устройство в этой сети.

Доступное число узлов получается из общего числа адресов - 2, так как первый и последний адреса отводятся на [[Адресация узлов сети|сетевой и широковещательный адреса]] соответственно.

Компьютеры с одинаковой сетевой частью находятся в одной [[../Классификация сетей по территории покрытия/Локальные сети (LAN)|локальной сети]] и могут легко обмениваться данными.

| Параметр                    | Октет 1  | Октет 2  | Октет 3  | Октет 4  |
| --------------------------- | -------- | -------- | -------- | -------- |
| **IP-адрес:** 192.168.1.13  | 11000000 | 10101000 | 00000001 | 00001101 |
| **Маска:** 255.255.255.0    | 11111111 | 11111111 | 11111111 | 00000000 |
| **Адрес сети:** 192.168.1.0 | 11000000 | 10101000 | 00000001 | 00000000 |

Общепринятые маски подсетей исторически связаны с классами IP-адресов (A, B, C). Граница между последовательностями единиц и нулей в маске соответствует границе между номером сети и номером узла в IP-адресе.

Октет может полностью относиться к сетевой части, полностью к узловой части, или делиться между ними, если граница раздела проходит внутри октета.

> ***Технология бесклассовой междоменной маршрутизации (Classless Inter-Domain Routing, CIDR)*** - это технология, основанная на использовании масок для более гибкого распределения адресов и более эффективной [[Маршрутизатор|маршрутизации]] (RFC 1517 — RFC 1520).

Она допускает произвольное разделение IP-адреса на поля для нумерации сети и узлов. При такой системе адресации клиенту может быть выдан пул адресов, более точно соответствующий его запросу, чем это происходит при адресации, основанной на классах адресов.

CIDR = количество бит сетевого адреса в маске, которое записывается после IP-адреса через слэш (/).

| Параметр          | Десятичный формат (IPv4) | CIDR             |
| ----------------- | ------------------------ | ---------------- |
| **IP-адрес узла** | 192.168.1.128            | 192.168.1.128/24 |
| **Маска подсети** | 255.255.255.0            | /24              |
| **Адрес сети**    | 192.168.1.0              | 192.168.1.0/24   |

Нестандартные маски — это маски, при которых границы сети проходят внутри октета (например, /25, /26, /27 и т. д.), а не строго по границам октетов (/8, /16, /24).

Например, если клиенту A требуется всего 13 адресов, то вместо выделения ему сети стандартного класса С (класса с наименьшим числом узлов — 256) ему может быть назначен пул адресов **193.20.30.0/28** (**11000001.00010100.00011110.00000000/28**). 

**193.20.30.0/28** интерпретируется следующим образом: «сеть, не принадлежащая ни к какому стандартному классу, номер которой содержится в 28 старших двоичных разрядах IP-адреса 193.20.30.0, имеющая 4-битовое поле для нумерации 16 узлов». Все это вполне удовлетворяет требованиям клиента A. Такой вариант более экономичен, чем раздача сетей стандартных классов «целиком».

![[../../img/маспод1.png]]

Справедливы следующие утверждения:

- значением префикса (номера сети) являются n старших двоичных разрядов IP-адреса;
- поле для адресации *узлов* состоит из (32 – n) младших двоичных разрядов IP-адреса;
- первый по порядку *номер узла* должен состоять только из нулей;
- количество адресов в пуле равно $2^{32–n}$.
