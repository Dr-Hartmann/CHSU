# Коммутатор

> ***Сетевой коммутатор (switch, свитч)*** — устройство, предназначенное для соединения нескольких [[../Каналы связи/Линии (каналы) связи. Узел. Абонент сети|узлов]] [[../Компьютерная сеть|компьютерной сети]] в пределах одного [[Сегментация сети|сегмента]] [^1].

Коммутаторы L2 выполняют функцию [[../Коммутация. Потоки данных|коммутации]], чтобы переупорядочивать данные от источника к концу назначения, узнавая [[Адресация узлов сети|физический адрес]] узла назначения из таблицы адресов коммутатора. При включении коммутатора эта таблица пуста, и он работает в режиме обучения. В этом режиме поступающие на какой-либо порт данные передаются на все остальные порты коммутатора. При этом коммутатор анализирует [[../Сообщение, пакет, кадр, сегмент (PDU)|кадры]] и, определив адрес хоста-отправителя, заносит его в таблицу.

Впоследствии, если на один из портов коммутатора поступит кадр, предназначенный для хоста, [[../Управление доступом к среде. MAC-адрес|MAC-адрес]] которого уже есть в таблице, то этот кадр будет передан только через порт, указанный в таблице. Если MAC-адрес хоста-получателя ещё не известен, то кадр будет продублирован на все интерфейсы. Со временем коммутатор строит полную таблицу для всех своих портов, и в результате трафик локализуется.

В отличие от [[Концентратор|концентратора]], который распространяет трафик от одного подключённого устройства ко всем остальным, коммутатор передаёт данные только непосредственно получателю. Это повышает производительность и безопасность сети, избавляя остальные сегменты сети от необходимости (и возможности) обрабатывать данные, которые им не предназначались.

![[../../img/комм1.png]]

Управляемый коммутатор L3 используется для организации сетей доступа, уровня агрегации, ядра. Преимуществом этого оборудования являются расширенные функции управления трафиком, простота настройки, подключения и управления, поддержка резервирования на уровне физических устройств.
